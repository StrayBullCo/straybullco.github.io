STRAY BULL CO. website starter
================================

Files:
- index.html: homepage and product preview
- style.css: responsive western styling
- script.js: small dynamic footer detail
- assets/: your uploaded hat photos and, if available, logo image

IMPORTANT BEFORE LAUNCH:
1. The product prices are intentionally marked "Coming soon".
2. Replace the Instagram and TikTok href="#" values in index.html with your actual profile URLs.
3. Replace hello@straybullco.com with an email address you control.
4. Add actual checkout links only after creating them with a payment provider (for example Stripe Payment Links).
5. Add clear shipping, return, privacy, and terms policies before accepting orders.
6. Confirm California sales tax and seller's permit obligations.
7. The brand mark in the header is typed "SB" as a temporary fallback; replace it with the exact logo asset when you have a transparent PNG/SVG version.
8. This is a static front-end starter, not a complete inventory or shopping-cart system.

PUBLISHING:
- Upload this folder to a GitHub repository.
- In Cloudflare Pages, connect the GitHub repository and deploy it as a static site.
- Add your domain in Cloudflare Pages and follow its DNS instructions.
- Test every link and checkout on mobile before launch.
